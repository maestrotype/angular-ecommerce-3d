# Client documentation (HTML)

Buyer-facing docs with the same dark visual language as `BACKEND_ARCHITECTURE_DIAGRAM.html`.

## Open

- Hub: [index.html](./index.html) (open in browser or VS Code / Cursor Simple Browser)
- Rebuild after editing Markdown sources: `npm run docs:client`

## Sources

Markdown in `docs/*.md` remains the editable source. This folder is **generated** for marketplace packages and comfortable reading.

## Not included (internal)
